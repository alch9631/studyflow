# StudyFlow interface

Mode: Operate. Keep the existing Geist type, cyan accent, neutral surfaces and dark theme.

The user wants a minimal app, especially on iPhone. Default screens show the content and controls needed for the next action. Do not add introductory paragraphs, reassuring commentary, repeated status messages or instructions above the task.

- Today is one structured task list. Every row uses the same text size and controls, including the first task; there are no separate Start or Resume buttons. Tapping a task opens session-length choices of 10, 30, 60 and 90 minutes before the timer starts, with no typing. Preserve elapsed time when resuming older sessions. Never hide tasks behind a disclosure.
- Task menus sit at the right edge of their task heading or row. Never attach an overflow menu to the Start button. Menus contain short actions; editors open separately.
- Adjust plan opens directly from an icon beside the Today heading. Keep it to the available adjustment actions and one short impact line per action; no repeated explanations or multi-day tables. Keep necessary plan health and undo controls inside it. Today has no Schedule section.
- The iPhone opens on Home with one encouraging sentence, a short summary, the next task and one action to start or resume work. Its icon-only native tabs are Home, Today, Calendar, Courses and Insights. The web planner keeps Today, Calendar and Courses as primary navigation.
- Materials keeps Add files visible and groups existing files inside a collapsed Uploaded materials disclosure with a file count. Open it after uploading or when linking to material preparation. Each file retains opening, optional task planning and deletion. Add files opens the native picker directly from an inline control and accepts several files; show Upload beside the filename or selected count, with progress during upload. Retain only failed files for retry. No separate upload panel, focus controls, repeated metadata or upload instructions.
- Course pages have no Start focus, topic Start or Add task controls. One pen beside each topic opens its notes and editing sheet; never expand topic rows with dropdowns. Keep existing task editing and notes available inside.
- Material filenames wrap within their row, including long names without spaces. Keep planning and deletion as compact icons beside the filename, never below it or overlapping it.
- Course rows show the name and exam countdown. Course settings, plan maintenance, task instructions and editing controls open on request.
- Active course cards have equal heights, with two lines reserved for the name and the countdown below. Topic rows swipe right to complete and left to confirm deletion; the pen editor also offers Delete for keyboard access. Keep native vertical scrolling and cancel interrupted gestures cleanly. Topic deletion removes its notes and future sessions while preserving logged study history and child topics.
- Calendar leads with dates and the agenda. On phones, Arrange and the unscheduled count refer to the selected day and exclude completed work. A full window gives a short explanation and a direct link to change the window. Placement tools stay compact and manual controls are collapsed.
- Exams opens from Courses on iPhone and from the navigation menu on the web. Show a proportional timeline, vertically scrollable months on phones, horizontally scrollable months from 640 px, and the full exam list. Use consistent course colors across all three views, count exams sharing a day, and keep date controls at least 44 px. Keyboard navigation follows the scroll direction; desktop calendar arrows supplement swiping. Gaps represent calendar days, never learning readiness. Official-date refresh and source status remain available.
- Insights leads with a chart. Explanations, history and detailed statistics are optional.
- Focus shows the timer, Pause and Finish, a visible notes box and an editable list of saved, dated notes beneath it. No Details & notes disclosure. Preserve notes across sessions and plan changes.

Use short labels, clear error recovery and at least 44 px touch targets. Preserve readable text sizes and accessible names. Verify English and German, portrait and landscape, light and dark, and the rendered result at iPhone widths.

Native app structure:

- Course rows open directly. Topics, Materials and Deadlines share one equal-width section bar; the gear in the header opens settings. Recall and coverage belong with Topics; plan maintenance belongs inside course settings. Materials has one upload toolbar, and unfinished deadlines appear first in date order.
- Use swipe-to-reveal for common row actions: right for Complete/Reopen; left for notes on Today, Reschedule on Calendar, and Delete on topics/materials/deadlines. Short swipes reveal tappable actions; deliberate full swipes run them on release. Every action has an equivalent tap control. Deletion requires confirmation. Close revealed actions when scrolling, changing pages, opening another row or backgrounding.
- Today keeps the course and duration only on unfinished rows. Completed rows show the title and checkmark. Lists scroll behind a compact native Liquid Glass tab bar with SF Symbols and dark material in dark mode. Enable native scroll minimization where supported. Let native content insets keep the final row clear of it.
- Remaining exams swipe right to mark done and left to edit the date. Results swipe right to edit a grade and left to unmark a pass. Confirm clearing a passing grade when unmarking. An info button retains details and tap alternatives without a three-dot menu.
- Optional information uses a small info button with a 44-point target. Back navigation uses a circular glass arrow; Session length closes with a top-right glass X.
- Settings opens from the tab headers. The catalog belongs in Add course. There is no Timetable screen on iPhone. Calendar rows show assigned times and omit duration estimates. Avoid duplicating these destinations in Settings.
- Plan adjustments use a sheet with status as text and one impact line per choice. Exam preparation opens by tapping the exam name. Insights leads with its weekly chart; history and detailed statistics start collapsed. Course progress stays inside Courses.
